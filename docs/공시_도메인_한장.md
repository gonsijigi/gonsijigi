# 공시 도메인 한 장 — DART 화면 읽는 법 + 코스피 주요 공시

> 발표 Q&A 방어용. 전 항목 **공식 출처(DART/OpenDART 가이드·KRX·법령) 교차 검증** 완료 (2026-07-08, 검증 에이전트 반박 통과).

## 1. DART 최근공시 화면 읽는 법

**비고 컬럼 약어** (OpenDART 공식 가이드 원문 — 마우스 올리면 툴팁으로도 표시):

| 약어 | 의미 | 성격 |
|---|---|---|
| **유** | 한국거래소 **유가증권시장본부**(코스피) 소관 공시 | 어느 시장 소관인가 |
| 코 | 코스닥시장본부 소관 | 〃 |
| 채 / 넥 / 공 | 채권상장법인 / 코넥스 / 공정거래위원회 소관 | 〃 |
| 연 | 연결(연결재무제표) 부분 포함 | 문서 상태 |
| **정** | **이 보고서 제출 후 정정신고가 있음** → 이건 구본, 최신본을 봐야 함 | 문서 상태 |
| 철 | 철회(간주)된 보고서 | 문서 상태 |

**IR 배지** = 그 회사가 DART 기업개황에 **자기 IR 홈페이지 주소를 등록**해둔 것. 클릭하면 회사 IR 사이트가 새 창으로 열림 (기업설명회 일정과 자동 연동되는 게 아님 — OpenDART 기업개황 API의 `ir_url` 필드).

**[기재정정] vs 비고 '정'** — 정정의 양면:
- 보고서명 앞 **[기재정정]**(파란색) = 내용이 바뀌어 **새로 제출된 최신본**에 붙음
- 비고 **정** = 정정으로 **대체된 구본**에 붙음 (열면 "최종문서가 아니므로 투자판단시 유의" 경고 + 최종본 이동 안내)
- **최종본 보는 법**: ①목록에서 접수일 가장 최근의 [기재정정] 건 ②공시통합검색의 '최종보고서' 체크(기본 체크됨) ③OpenDART는 `last_reprt_at=Y`
- 💡 우리 서비스 연결: **정정마다 접수번호가 새로 발급**됨 → 폴러가 [기재정정] 3건을 각각 잡는 건 버그가 아니라 DART 구조 그대로. (개선 아이디어: `last_reprt_at=Y`로 최종본만 — 로드맵)

## 2. 코스피(유가증권시장) 주요 공시 톱10 — 왜 중요하고 뭘 봐야 하나

| 공시 | 왜 주가에 중요 | 꼭 볼 필드 |
|---|---|---|
| **주요사항보고서(유상증자결정)** | 신주 발행 = 지분 **즉시 희석**. 목적 따라 호악재 갈림 | 증자방식(주주배정/제3자배정) · 신주수/할인율 · **자금조달 목적** |
| **주요사항보고서(CB/BW 발행결정)** | 나중에 주식이 되는 **잠재 물량(오버행)** + 리픽싱 시 희석 가속 | 전환(행사)가액·리픽싱 최저가 · 발행대상 · 규모/전환청구시기 |
| **자기주식 취득/처분 결정** | 취득=유통물량↓·환원 신호, 처분=물량 출회 | 수량·금액·기간 · 목적(소각 여부) · 신탁은 전액매수 비보장 |
| **단일판매·공급계약체결** | 코스피는 매출 5%(대규모 2.5%)↑ 계약만 공시 = 대형 수주 | 매출 대비 비율 · **계약기간**(장기면 연환산) |
| **공정공시** (잠정실적·전망) | 정기보고서보다 먼저 나오는 실적 → 선반영 | 수치의 전년比 · 전망치/잠정치 구분 |
| **조회공시 요구·답변** | 거래소가 풍문 해명 요구 = 중대 루머 공식화 | 답변(부인/미확정/확정) · 미확정 시 재공시 기한 |
| **대량보유상황보고(5%룰)** | 큰손 진입·이탈, 경영권 분쟁 신호 | **보유목적**(경영권 영향이면 분쟁 신호) · 변동 내역 |
| **임원·주요주주 소유상황보고** | 내부자의 실제 매매 = 경영진의 주가 판단 | 변동 사유(장내매수/매도) · 수량·단가 |
| **매매거래정지** | 팔 수도 살 수도 없음 — 유동성 리스크 극단 | **정지 사유**(조회공시용 일시정지 vs 실질심사·감사의견) · 해제 조건 |
| **감사보고서(감사의견)** | 한정=관리종목, 부적정·의견거절=상장폐지 사유 — 최대급 | 의견 구분 · **계속기업 불확실성** 기재 여부 |

## 3. 희석 3형제 — 유상증자 vs CB vs BW

- 셋 다 종착점은 신주 발행 = **지분 희석**. 차이: 유상증자=**즉시 확정** 희석 / CB·BW=전환·행사 때 실현되는 **잠재** 희석(그 전까진 오버행으로 주가 압박)
- **리픽싱**: 주가 하락 시 전환가액이 최초가의 70%까지(주총 특별결의 시 그 밑까지) 내려가 **발행 주식수가 늘어남** → 최초 공시 때보다 희석 커질 수 있음
- **제3자배정 vs 주주배정**: 주주배정은 지분율만큼 청약권(참여하면 희석 회피, 불참해도 신주인수권증서 매도 가능). 제3자배정은 **선택권 없는 희석** + 배정 대상 정체(투자조합? 최대주주?)·보호예수·납입 연기 반복이 위험 신호. 할인율 상한: 제3자배정 10% / 일반공모 30% (증발공 규정 §5-18)
- **조달 목적 읽기**: 시설투자 → 일반적으로 성장 투자로 해석되는 경우가 많음 / 운영자금·채무상환 위주 → 재무 악화 신호로 읽히는 경우가 많음 ← **"일반적으로~경우가 많다"까지가 우리 서비스의 선. "호재다/좋은 시그널"은 단정이라 가드레일 위반**

## 4. 발표 Q&A 예상 공격과 방어

- **"CB도 위험한데 왜 검토 큐로 안 보내요?"** → "정확한 지적입니다. 금융위가 2021·2024년 두 차례 CB 규제를 강화했을 만큼(리픽싱 제한·콜옵션 공시) 규제당국도 고위험으로 봅니다. 현재 키워드는 보고서 6.6절의 6종이고, CB·BW를 같은 등급으로 올리되 사모 여부·리픽싱 최저가·전환주식비율로 **세분화하는 게 로드맵**입니다 — 오늘은 '일반은 즉시, 위험은 검토'라는 게이트 구조 자체를 보여드리는 게 목적입니다."
- **"[기재정정]이 3건씩 알림 오면 스팸 아닌가요?"** → "DART가 정정마다 새 접수번호를 발급하는 구조 그대로입니다. `last_reprt_at=Y`(최종본만) 옵션으로 묶는 게 다음 단계입니다."
- **"비고의 '유'는 뭔가요?"** → "유가증권시장본부 소관이라는 뜻입니다. '정'이 붙으면 구본이라 최신 [기재정정]본을 봐야 하고, 저희 알림 카드 링크는 접수번호 단위라 해당 본으로 정확히 갑니다."
