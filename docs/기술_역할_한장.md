# 기술 스택 역할 한 장 정리 — "이게 뭐 하는 애지?" 용

> 발표 Q&A 대비용. 각 줄: **이게 뭔가 → 우리 프로젝트에서 하는 일 → 발표에서 한 줄**.
> '왜 이걸 골랐나'는 [발표_초안.md](발표_초안.md)·[발표_대본.md](발표_대본.md)의 [수업→적용→왜] 참고.

## 웹 계층

| 기술 | 이게 뭔가 | 우리 프로젝트에서 |
|---|---|---|
| **uvicorn** | 파이썬 웹앱을 실제로 실행해주는 **서버 프로그램**(ASGI 서버). FastAPI는 '앱 설계도'고, uvicorn이 그걸 '켜서' 포트(8000)에서 요청을 받는다 | `uvicorn app.main:app` — 우리 앱을 구동하는 엔진. `--reload`는 코드 저장 시 자동 재시작(개발용) |
| **FastAPI** | 파이썬 웹 프레임워크 — URL(라우트)마다 어떤 함수를 실행할지 정의 | `/ask` `/watchlist/` `/admin/` `/poll` 등 모든 화면·API가 FastAPI 라우터 |
| **SSE** (Server-Sent Events) | 서버가 응답을 **조금씩 흘려보내는** HTTP 스트리밍 방식 | `/ask` 답변이 타자 치듯 스트리밍 — 사용자가 빈 화면을 기다리지 않게 |
| **pydantic** | 데이터 형식 검증 라이브러리 — "이 필드는 문자열, 이건 리스트"를 강제 | `/ask` 입력 검증 + **해석 구조화**(유형/사실/주의 3필드 — OutputParser의 뼈대) |

## 에이전트 계층

| 기술 | 이게 뭔가 | 우리 프로젝트에서 |
|---|---|---|
| **LangGraph** | LLM 작업 흐름을 **상태 그래프**(노드+분기)로 짜는 프레임워크. 체인(일직선)과 달리 조건 분기·중단이 자연스러움 | `가드레일→파싱→조회→해석→위험도→알림/HITL` 그래프. 조건부 분기 3개(차단/되묻기/고위험), checkpointer+thread_id로 사용자별 대화 맥락 |
| **LangChain** (계열 라이브러리) | LLM 앱의 부품 모음 — 우리는 통짜 LangChain이 아니라 **필요한 부품만** 씀 | `langchain-postgres`(pgvector 저장/검색), `langchain-ollama`(임베딩 호출), `langchain-text-splitters`(재귀 청킹), `PydanticOutputParser`(구조화 출력) |
| **OpenAI SDK** | OpenAI **호환 형식**으로 LLM을 호출하는 클라이언트 (OpenAI 서비스 자체가 아님!) | `llm/client.py` — 이 표준 덕에 로컬 Ollama ↔ 수업 vLLM을 `.env` 3줄로 교체 |

## LLM·RAG 계층

| 기술 | 이게 뭔가 | 우리 프로젝트에서 |
|---|---|---|
| **Ollama** | 내 컴퓨터에서 LLM을 돌려주는 **로컬 모델 서버** (`localhost:11434`, API 키 없음) | 해석 LLM(gemma3n)과 임베딩(bge-m3) 둘 다 서빙 — 온프레미스라 데이터 외부 유출 없음 |
| **gemma3n:e4b** | 구글의 경량 오픈소스 LLM (7.5GB) | 공시 **해석 생성** 담당. 다운되면 폴백 요약으로 대체 |
| **bge-m3** | 문장을 1024개 숫자(벡터)로 바꾸는 **임베딩 모델** — 비슷한 뜻이면 가까운 벡터 | 공시 청크와 질문을 벡터화 → 유사 공시 검색의 기반 |
| **PostgreSQL + pgvector** | 관계형 DB + **벡터 검색 확장** — 벡터·메타데이터·SQL을 한 곳에서 | 과거 공시 원문 159청크 저장, 거리≤0.5 유사 검색 → 해석의 '과거 유사 사례' 근거 |
| **vLLM** (로드맵/수업) | GPU 서버용 고성능 LLM 서빙 엔진 | 수업 제공 엔드포인트. OpenAI 호환이라 우리 클라이언트로 그대로 접속 가능 |

## 데이터·인프라 계층

| 기술 | 이게 뭔가 | 우리 프로젝트에서 |
|---|---|---|
| **DART OpenAPI** | 금감원 전자공시 공식 API — 공시 목록·원문 무료 제공 | `dart_search`(목록)·`get_document_text`(원문)·corpCode 매핑. 실패 시 mock 폴백 |
| **Docker / docker-compose** | 프로그램을 '컨테이너'로 격리 실행 — 팀원 누구나 같은 환경 | pgvector DB를 명령 한 줄로 띄움 (`compose up -d db`). 앱 이미지 빌드도 CI에서 검증 |
| **GitHub Actions (CI)** | push/PR마다 자동으로 테스트를 돌려주는 로봇 | 스모크 10종(가드레일·출처·마스킹 불변) + Docker 빌드 — 초록불 없으면 머지 금지 |
| **Redis / K8s** (로드맵) | 인메모리 큐·저장소 / 컨테이너 오케스트레이션 | **선언만** — 현재 큐는 인메모리, 배포는 Docker까지. 인터페이스 유지 교체 설계 |

## 한 문단 요약 (발표 리듬용)
"**uvicorn**이 **FastAPI** 앱을 켜면, 질문은 **LangGraph** 그래프를 타고 흐릅니다. 가드레일과 파싱을 지나 **DART API**로 공시를 가져오고, **bge-m3**가 벡터로 바꿔 **pgvector**에서 과거 유사 공시를 찾아오면, **Ollama**의 gemma가 그 근거로만 해석을 만들고, 코드가 출처와 면책을 붙여 **SSE**로 흘려보냅니다. 이 전부를 **Docker**와 **CI**가 재현 가능하게 지킵니다."
